# Service icons

Local assets used to identify services in the trace diagram. They are embedded as
data URLs; viewing a trace does not request images from third-party servers.
The Lumen mark reuses the application's existing CSS brand mark.

- **IBM Verify:** the icon embedded in IBM's [Verify Operator manifest](https://github.com/IBM-Security/verify-operator/blob/fcf592bc5f9c2dac71e7fcb2d548952297483a16/config/manifests/bases/ibm-security-verify-operator.clusterserviceversion.yaml), extracted without changing the image.
- **Vault and MySQL:** [Devicon](https://github.com/devicons/devicon/tree/6a37858047b0e8d9c9c0e68f4a071fc410652e89/icons), original SVG icons. License: `LICENSE-devicon`.
- **OpenAI, xAI, Claude/Anthropic and Tavily:** [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/8a1b2821bb768c484fe8da20c5e1838b6bf551a9/packages/static-svg/icons), original SVG icons. License: `LICENSE-lobe-icons`.

used by this demonstration and do not imply endorsement.
